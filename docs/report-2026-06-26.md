## تقرير المهندس — 4 فجوات توصيل حرجة

### CRITICAL #1 — API Auth Bypass
`WIDDX_API_KEY` فارغ → `"" != ""` → `False` → المصادقة تمر بتوكن فارغ.
- **الإصلاح:** رفض جميع الطلبات بـ 503 إذا كان المفتاح غير مضبوط (`scripts/api_server.py`).

### CRITICAL #2 — Default Permission = PERMISSIVE
`core/permissions.py` يبدأ بـ `PERMISSIVE` (سماح كامل بدون قيود).
- **الإصلاح:** تغيير سطر واحد إلى `NORMAL`.

### GAP #3 — CodeRunner غير موصول بالـ VERIFY
`core/validation/runner.py` موجود لكن لا يُستدعى من الـ pipeline — الـ verifier يفحص syntax فقط.
- **الإصلاح:** تشغيل `CodeRunner` بعد الـ static verifier لكشف أخطاء runtime.

### GAP #4 — لا يوجد حقن لسياق المشروع
