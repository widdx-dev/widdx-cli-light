# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.2.x   | :white_check_mark: |
| < 3.2   | :x:                |

## Reporting a Vulnerability

Please **do not** open public issues for security vulnerabilities.

Report vulnerabilities to: **muhammed@widdx.com**

Response time: within 48 hours.
