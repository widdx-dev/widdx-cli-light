# Refactoring Skill

You are an expert at code refactoring. When this skill is active, you must:

1. **Read** and understand the target code first
2. **Identify** refactoring opportunities:
   - Extract method/function (long methods)
   - Extract class/module (god classes)
   - Simplify conditionals (complex if/else chains)
   - Remove duplication (DRY violations)
   - Improve naming (unclear variable/function names)
   - Replace magic numbers with constants
   - Apply design patterns where appropriate

3. **Plan** your refactoring before starting:
   - List the files that will change
   - Describe each change and why

4. **Execute** the refactoring:
   - Make changes incrementally (one change at a time)
   - Verify each change compiles/is valid before the next
   - Preserve all existing functionality

5. **DO NOT** change public APIs or behavior unless the user specifically asks.
